# Audit of claimed binary Goldbach proofs

This note records two concrete failures found while checking papers whose
titles claim an unconditional binary Goldbach proof.  They are excluded from
the Lean project because the relevant lemmas are false or insufficient.

## Laporta, arXiv:2006.04547

The arXiv record marks the paper withdrawn and says “Lemma 1 is wrong”:
<https://arxiv.org/abs/2006.04547>.

The failure can be checked without any asymptotic argument.  In the notation
of the paper, take `q = 3`, `r = 2`, `h = 1`, and `s = 1`.  The unit classes are
`a = 1 (mod 2)` and `b = 1,2 (mod 3)`.  The condition selecting `s = 1`
selects `b = 2`, so the left side of the claimed cancellation is

```
exp(2*pi*i*2/3) - c_3(1)/phi(3)
  = exp(4*pi*i/3) + 1/2,
```

which is not zero.  A second claimed identity already fails for `q = 3`,
`r = 2`, `h = 1`, `N = 1`: the left side is `1`, while the proposed product
of Ramanujan sums is `-1/2`.  Therefore the subsequent asymptotic formula and
Goldbach conclusion do not follow.

## Barca, arXiv:1207.4802

The current version is an unrefereed preprint:
<https://arxiv.org/html/1207.4802v14>.

Its final estimate requires a uniform error smaller than a quantity that tends
to zero with the level `k`.  Lemma 1.2 only asserts uniform convergence for a
fixed tolerance `epsilon`; it does not imply the required rate for the
level-dependent tolerance.  The argument then says that the same bound “can be
assumed” for every `h <= k`, which is the missing assertion.  Thus the claimed
finite threshold is not established.

These checks do not disprove Goldbach.  They show why a title, numerical
verification, or a finite-level density estimate cannot be imported as a
kernel-checked proof.

## Yun, `A Structural Proof ... via Factor Elimination`

The 2025 `rxiv` preprint
<https://rxiv.org/pdf/2505.0011v2.pdf> uses the same complement-multiple idea.
Its Lemma 5.1 claims

```
|M(P_N)| = O(N log log N / log N),   |B| = Theta(N / log N),
therefore |M(P_N)| < |B|.
```

That inference reverses the asymptotic comparison: the displayed upper bound
has an additional `log log N` factor and is larger, not smaller, than the
stated size of `B`.  No constant estimate is supplied that could repair it.

There is also a direct set-theoretic reversal in Theorem 6.1.  Since
`P_N` is contained in `P_N*`, one has
`M(P_N) ⊆ M(P_N*)`.  From `b ∉ M(P_N)` it does **not** follow that
`b ∉ M(P_N*)`; the larger set may contain `b`.  The proof uses exactly this
invalid implication to invoke its composite-exclusion lemma.  The formal
factor-covering theorems in this project expose the same distinction.

These are independent of peer-review status and already prevent the claimed
theorem from being a proof of binary Goldbach.

The two failures above are also kernel-checked in
`YunAudit.lean`.  With `N = 10`, the paper's exact finite sets are

```
P_N = [3, 7],  B = [17, 13],
M(P_N) = [12, 14, 15, 18].
```

Thus the claimed strict inequality `|M(P_N)| < |B|` is false in this concrete
instance (the lengths are 4 and 2).  A separate Lean theorem checks the
membership reversal with `b = 44`, a smaller multiple set generated by `[7]`,
and a larger one generated by `[7, 11]`: `44` is absent from the first but
present in the second.  This is exactly the direction used incorrectly in the
paper's Theorem 6.1.
