# 国保足迹

日常编辑时直接双击 `打开国保足迹.cmd`：启动器会检查并启动本地保存服务，然后自动打开编辑页；无需手动输入命令或网址。该编辑页会将每次修改自动保存到 `data/visits.private.json`。直接打开 `index.html` 仍可使用，但受浏览器安全限制，记录只能保存在该浏览器中，不能自动写入博客数据。名录页支持按省份、批次、年代、类别和到访状态筛选，并可按省份、批次或年代分组，填写到访时间与备注。页面默认显示北京市；选择“全部省份”会显示全国分页名录。

“到访统计”是 `index.html?view=stats` 独立视图，与名录页共享浏览器记录，提供年度/月度趋势、各批完成度、类别分布和省份进度。名单默认每页显示 20 项，支持输入页码直达；按批次查看时使用该批公告序号排序。页面列表只展示名称，正式编号仍保留在详情、搜索和基础数据中。年代筛选按完整时代中的最早阶段归类，黄色标签仍显示公告所载的完整时代；无法判断最早阶段的记录归入“其他”，不单设“跨时期”。“青铜时代”属于考古学分期：以青铜时代为最早阶段的记录归入“夏商周”，“新石器至青铜时代”则按最早阶段归入“史前”。

公告中的“一作”异名经过规范化：仅行政前缀或单字正误差异直接合并，确有辨识价值的异名保存在 `alias` 字段并以小号括号显示。

## 数据口径

- 第一至第八批独立全国重点文物保护单位：5,058 处。
- 第四至第八批与既有国保合并的项目：238 项；页面默认不计入，可单独开启。
- 到访记录保存在当前浏览器的 `localStorage` 中，不会写回基础名单。
- “备份记录”导出 JSON，可用于防止浏览器数据丢失、迁移到其他浏览器，以及日后生成博客公开数据；“导入备份”用于恢复该 JSON。
- “导出当前 CSV”会把当前筛选结果和个人记录导出为表格，适合在 Excel 中核对或另行统计，不参与页面日常保存。
- CSV 使用 UTF-8 BOM，可直接用 Excel 打开；`period` 是归并后的年代分类。`visit_time` 接受年份、年月、完整日期或自由文本。
- 年月日推荐使用 `2024`、`2024-05`、`2024-05-18`；也支持 `/`、`.` 或“年月日”分隔。年度统计读取所有含年份的记录，月度统计只读取含月份的记录。

公告采用公布时的地名；跨省项目按公告地址中第一个省份归档，完整地址仍保留在 `location` 字段。

## 发布到静态博客

静态博客无法读取浏览器 `localStorage`，因此自动发布必须通过本地编辑服务维护仓库记录文件：

1. 双击 `打开国保足迹.cmd`。
2. 在自动打开的页面中更新到访记录，页脚显示“已自动保存到博客数据”后即可关闭。
3. 照常运行 `npm run deploy:all`。

`npm run deploy:all` 的前置步骤会先校验国保记录；其中每一次 Hexo 生成都会通过 `after_generate` 钩子自动复制页面到 `public/heritage/`，读取私有记录并生成公开只读数据。公开数据只包含到访状态和时间，不包含个人备注；`visits.private.json` 已加入 `.gitignore`，不会被 Git 提交。博客导航中的 `Heritage` 指向 `https://kangaroogao.com/heritage/`。

原先通过双击 HTML 保存的浏览器记录不会自动迁移到本地服务。首次切换时先在原页面“备份记录”，然后在本地服务页面“导入备份”一次；此后无需再手工导出。

## 文件

- `index.html`：本地入口。
- `data/全国重点文物保护单位.csv`：完整结构化数据，预留个人记录列。
- `data/units.js`：供本地页面直接读取的数据。
- `data/runtime.js`：本地/公开只读运行模式配置；公开版本由 Hexo 自动生成。
- `data/visits.private.json`：本地服务自动维护的私有记录，不提交 Git、不复制到博客。
- `scripts/build_data.py`：重新抓取、校验并生成 CSV/JS 的脚本。
- `scripts/editor_server.mjs`：本地编辑服务。
- `scripts/prepare_publish.mjs`：`npm run deploy:all` 前的记录校验。
- `打开国保足迹.cmd`：Windows 一键启动并打开本地编辑页。
- 博客根目录 `scripts/heritage_publish.js`：Hexo 自动发布钩子。

## 数据来源

- 国务院第一至第八批公布通知，使用维基文库收录的政府公文文本；政府公文属于公有领域。
- 标准化编号与分类辅助数据来自 [china-cultural-heritage](https://github.com/lingdian1226/china-cultural-heritage)，许可证为 CC BY 4.0。
- 第八批数量同时以[国家文物局公布名单](https://www.ncha.gov.cn/art/2019/10/18/art_2289_157100.html)校验。

重新生成数据：

```powershell
python .\scripts\build_data.py
```
