# 本轮候选路线与反例搜索

日期：2026-09-14。结论：没有找到强哥德巴赫反例，也没有完成其证明。
本轮尝试了一条本项目此前没有计算检验过的路线，并证伪了其中一个加强引理。
以下是独立组织的研究方案，不声称在数学文献中首次提出。

## 立方根筛与素因子奇偶性

固定偶数 N >= 4，令 z 为 N 的立方根向下取整，定义

\[
A_N=\{p\le N/2:p\text{ 为素数，且 }N-p\text{ 没有不超过 }z\text{ 的素因子}\}.
\]

令 Omega(m) 表示素因子个数，按重数计算，lambda(m)=(-1)^Omega(m)。
对 p 属于 A_N，m=N-p >= 2，且 m <= N-2 < (z+1)^3。
若 m 有至少三个素因子，它们每个都至少为 z+1，乘积将超过 m，矛盾。
因此 m 只能是素数或半素数，包括素数平方。

写 S_N=|A_N|，L_N 为 A_N 上 lambda(N-p) 的和，r_N 为不计交换顺序的素数分解数。
所有哥德巴赫分解都保留在这个筛中：把较小素数取作 p，则较大素数 q >= N/2 > z。
故有精确恒等式

\[
2r_N=S_N-L_N.
\]

这一恒等式的数学推导如上；本项目已在
[SmallFactor.lean](../GoldbachResearch/SmallFactor.lean) 中形式化其关键结构引理
`rough_prime_or_semiprime`，但尚未形式化一般的 Omega/lambda 理论。
实验使用最小素因子递推独立计算 Omega，并与直接素性计数逐项交叉检查。

这给出一条研究路线：找显式 N0 和固定 delta > 0，证明对每个偶数 N >= N0，

\[
S_N>0,\qquad L_N\le(1-\delta)S_N.
\]

再核验 4 <= N < N0，就能完成哥德巴赫证明。
其中 S_N>0 与严格不等式 L_N<S_N 合起来只是原猜想的等价重述；
固定比例的节省是更强的未证目标。恒等式本身没有解决下界。

## 一个被实际推翻的候选引理

最简单的猜测是 L_N <= 0，即筛后素数至少占一半。它是假的。
N=68 时 z=4，保留下来的 p 与补数为：

| p | 68-p | 类型 | lambda(68-p) |
| --- | --- | --- | --- |
| 3 | 65 = 5*13 | 半素数 | +1 |
| 7 | 61 | 素数 | -1 |
| 13 | 55 = 5*11 | 半素数 | +1 |
| 19 | 49 = 7*7 | 半素数 | +1 |
| 31 | 37 | 素数 | -1 |

所以 S_68=5，L_68=1，r_68=2。
这反驳的是候选加强引理，而不是哥德巴赫猜想：68=7+61=31+37。
[ParityExample.lean](../GoldbachResearch/ParityExample.lean) 由 Lean 内核验证了上述完整列表、
素数补数列表、素性判定、乘积分解，以及多数不等式的否定。

对每个 4 <= N <= 20000 的偶数进行了数值诊断：恒等式均成立，
L_N>0 恰好出现于 N=68,98,326,332,632。
观测到的最小比例 2r_N/S_N 为 4/5，在 N=68 达到。
这些事实不能推导 N>20000 时的符号，也不能给出适用于所有 N 的固定比例节省。

## 现有理论是否足够

这里不仅需要 Liouville 函数在全部整数上的平均抵消，
而是需要它在“素数平移且经过立方根筛”的集合上，对每个 N 抵消。
两者的支撑集和量词不同。

[Ford--Maynard 的素数检测筛](https://arxiv.org/abs/2407.14368)
能在合适的 Type I、Type II 估计下给出素数下界。
这提示研究双线性算术信息的价值，但必须先对本问题的序列验证那些估计；
不能把该框架直接当作哥德巴赫定理。

[Mangerel 的 Liouville Goldbach 型结果](https://arxiv.org/abs/2404.12117)
研究全部整数上的 Liouville 卷积，不能直接改成这里带素数和筛选约束的 L_N。
[LiouvilleToy.lean](../GoldbachResearch/LiouvilleToy.lean) 还形式化了一个最小符号模型：
在 N=5 时，卷积绝对值严格小于 N-1，但没有两个位置同时取负号。
所以即使接受这种全部整数上的卷积界，也仍缺少把负号限制到素数支撑的引理。
[Tao 对奇偶问题的说明](https://terrytao.wordpress.com/2007/06/05/open-question-the-parity-problem-in-sieve-theory/)
也区分了普通分布信息与素因子奇偶性的关联信息。

甚至 S_N>0 都有独立障碍：普通线性筛在分布水平 D 约为 N^(1/2)、筛选界 z 约为 N^(1/3)
时，参数 log(D)/log(z) 约为 3/2，位于其下界筛函数为零的范围。
因此本路线目前有两个未解决输入，而不是一个已经完成的证明。

## 对哥德巴赫本身的搜索

可复现程序为 [search.py](../experiments/search.py)，结果为
[summary.json](../experiments/results/summary.json)。全部运算使用整数。

| 搜索对象 | 范围或数量 | 结果 |
| --- | --- | --- |
| 连续小整数范围 | 所有 4 <= N <= 1000000 的偶数，共 499999 个 | 全部找到分解 |
| 超过已发表验证界限的选定目标 | 4000 个，4*10^18 < N < 2^64 | 全部找到分解 |
| 大数搜索未判定目标 | 候选首项上限为 100000 | 0 个 |
| 独立 Lucas 证书 | 3 个大数分解，递归核验 47 个素数节点 | 全部通过 |

4000 个目标包括：4*10^18 之后的前 1000 个偶数、2^64 之前的最后 1000 个偶数、
1000 个素数连乘积的倍数，以及 1000 个固定随机种子生成的偶数。
连乘积倍数会主动排除所含的小素数候选，因为这些 p 整除 N-p。
这次结果是有限抽查，不能描述为验证了整个区间 (4*10^18,2^64)。
也不声称这些抽查对象是其他项目未曾检查过的数。

最难样本（按本次找到的最小首项排序）之一为

\[
4000000000000000016=1213+3999999999999998803.
\]

其两项素性有单独保存的 Lucas 证书，且精确和式已核验。
完整分解列表在 [large-witnesses.jsonl](../experiments/results/large-witnesses.jsonl)。

另有一组针对性压力测试扫描全部 30315 个 `2*41#` 倍数和全部 15 个 `2*47#` 倍数，
都在首项 `p <= 1000` 时找到分解。最难样本之一是

\[
16377791685669714300=331+16377791685669713969.
\]

这只排除了有限的连乘积家族和有限首项范围；没有排除更大的素数首项，也不是区间验证。

大数素性测试使用 SymPy 1.14.0。其[官方文档](https://docs.sympy.org/latest/modules/ntheory.html#sympy.ntheory.primetest.isprime)
说明，对小于 2^64 的输入，isprime 给出确定性结果；本次所有输入均严格位于该范围。
如果达到首项上限仍找不到分解，程序将目标记为 unresolved，绝不视为反例。
反例必须排除全部 p <= N/2，而不是只排除一个固定候选上限。

[已发表的 4*10^18 验证](https://sweet.ua.pt/tos/bib/4.12.html)
是外部背景；本次连续小范围搜索用于程序核对，远未刷新它。

## 证书与信任边界

证书使用完全因数分解形式的 Lucas 素性判据：递归证明 n-1 的各个素因子 r 后，
找到 a 满足 a^(n-1)=1 (mod n)，并对每个 r 检查

\[
\gcd\bigl(a^{(n-1)/r}-1,n\bigr)=1.
\]

其理由是：对 n 的任意素因子 l，a 在模 l 下的阶整除 n-1，
而所有 gcd 条件迫使该阶包含 n-1 的全部素数幂因子，故阶恰为 n-1。
再由阶整除 l-1 得 l >= n，因此 n=l 为素数。

生成器可调用 SymPy 分解 n-1；[独立验证器](../experiments/verify_certificates.py)
仅使用 Python 标准库整数、模幂和 gcd，不依赖生成器给出的素性判断。
对错误和式、缺失因数、重复因数和能通过 Fermat 测试的合数 341 都有拒绝测试。

批量搜索与大数 Lucas 证书尚未 Lean 形式化。
Lean 在本轮验证的是 N=68 的加强命题反例，以及两个真实的 68 的素数分解。
这三个验证层次不能互相替代。
