# 一次构建中的字数统计

继续使用 `npm run deploy:all`。现在只需一次 Hexo 构建和一次部署；`npm run build` 也会同步更新统计，无需先发布网页。

`scripts/word_stats.js` 在 Hexo 渲染好文章后、生成页面前运行：

1. 用与 `hexo-wordcount` 一致的规则统计正文，保留精确整数。
2. 更新 `source/journey/index.md` 的文章字数和年份合计，并同步更新当前内存中的页面内容，因此本次生成的 HTML 就包含新字数。
3. 写入 `统计/字数统计` 的游记统计、文章统计（游记及指定额外文章）、读书笔记统计三份报告。

之前的 Python 脚本从线上文章页读取显示字数，例如将 `1.2k` 当成 1200 后汇总。现在直接使用本地正文的精确值，汇总后才显示成 `k`，总数可能因此略有变化。文章详情按发表时间排列，年份总数采用精确整数。

计数规则沿用当前安装的 `hexo-wordcount`：中文逐字、英文和数字按词计数，普通标点不计。HTML 标签及链接地址属性不计，链接显示文字计入；若网址本身就是显示文字，则按可见文本处理。Front Matter 与网页头部的文章标题、日期、标签等元信息不计，正文里的标题、表格及代码文字计入。

统计使用 Hexo 当前可发布的文章集合，排除未发布草稿以及配置为不显示的未来文章。行程索引中的“行程轨迹汇总”按原规则不显示字数；找不到索引引用的本地已发布文章时会中止构建，避免发布旧字数。

`lib/word-stats.cjs` 保存计数、索引更新和报告生成逻辑，`EXTRA_POSTS` 是原有四篇额外文章的名单。`统计/blog_stat.py` 保留为旧命令入口，改为调用一次本地 Hexo 构建，不再抓取线上网页。
