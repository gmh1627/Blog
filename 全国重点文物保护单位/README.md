# 国保足迹

打开 `index.html` 即可使用，无需安装依赖或启动服务器。页面支持按省份、批次、年代、类别和到访状态筛选，并可按省份、批次或年代分组，填写到访时间与备注。统计区提供年度/月度到访趋势、各批完成度和到访类别分布。

名单默认每页显示 20 项；按批次查看时使用该批公告序号排序。页面列表只展示名称，正式编号仍保留在详情、搜索和导出数据中。

## 数据口径

- 第一至第八批独立全国重点文物保护单位：5,058 处。
- 第四至第八批与既有国保合并的项目：238 项；页面默认不计入，可单独开启。
- 到访记录保存在当前浏览器的 `localStorage` 中，不会写回基础名单。
- “备份记录”导出 JSON，可在其他浏览器导入；“导出当前 CSV”会带上当前筛选结果和个人记录。
- CSV 使用 UTF-8 BOM，可直接用 Excel 打开；`period` 是归并后的年代分类。`visit_time` 接受年份、年月、完整日期或自由文本。
- 年月日推荐使用 `2024`、`2024-05`、`2024-05-18`；也支持 `/`、`.` 或“年月日”分隔。年度统计读取所有含年份的记录，月度统计只读取含月份的记录。

公告采用公布时的地名；跨省项目按公告地址中第一个省份归档，完整地址仍保留在 `location` 字段。

## 文件

- `index.html`：本地入口。
- `data/全国重点文物保护单位.csv`：完整结构化数据，预留个人记录列。
- `data/units.js`：供本地页面直接读取的数据。
- `scripts/build_data.py`：重新抓取、校验并生成 CSV/JS 的脚本。

## 数据来源

- 国务院第一至第八批公布通知，使用维基文库收录的政府公文文本；政府公文属于公有领域。
- 标准化编号与分类辅助数据来自 [china-cultural-heritage](https://github.com/lingdian1226/china-cultural-heritage)，许可证为 CC BY 4.0。
- 第八批数量同时以[国家文物局公布名单](https://www.ncha.gov.cn/art/2019/10/18/art_2289_157100.html)校验。

重新生成数据：

```powershell
python .\scripts\build_data.py
```
